EdgeDesk uses EdgeAlphix servers and selects an available relay based on location. Devices on the same local network can connect directly.

The release includes installers, source code, patches and SHA256 checksums. EdgeDesk and the original RustDesk code are licensed under GNU AGPL-3.0.

Android APKs use the EdgeDesk release signing key. The iOS IPA needs Apple signing before installation. macOS notarization and Windows code signing require signing credentials.
